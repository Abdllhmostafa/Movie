1 الطبقة الأولى: العرض وإطلاق الطلب (Presentation Layer)

يبدأ المسار عند فتح التطبيق ودخول شاشة الـ HomeScreen، حيث يتم تزويدها بـ MovieCubit واستدعاء جلب الأفلام فوراً:

lib/features/layout/presentation/layout_screens/home_screen.dart 
BlocProvider(
  create: (context) {
    final remoteDataSource = MovieRemoteDataSourceImpl();
    final repo = MovieRepoImp(remoteDataSource);
    final getAllMoviesUseCase = GetAllMovies(repo);
    return MovieCubit(getAllMoviesUseCase: getAllMoviesUseCase)..fetchMovies();
  },
  child: const HomeScreenContent(),
);
2 مدير الحالة: (MovieCubit)

يقوم الـ Cubit بتغيير الحالة فوراً إلى التحميل (Loading) حتى تظهر علامة الانتظار للمستخدم، ثم يستدعي الـ UseCase:

lib/features/layout/presentation/maneger/movie_cubit.dart 
Future<void> fetchMovies() async {
  emit(MovieLoadingState()); // 1. إظهار مؤشر التحميل
  final result = await getAllMoviesUseCase.call(); // 2. طلب البيانات

  result.fold(
    (failure) => emit(MovieErrorState(failure.message)), // في حالة الخطأ
    (movies) => emit(MovieSuccessState(movies)),         // في حالة النجاح
  );
}
3 طبقة النطاق: حالة الاستخدام والعقد (Domain Layer)

هذه الطبقة نقية تماماً (Pure Dart) لا تعتمد على Flutter أو Dio أو أي مكتبة خارجية. وظيفتها تحديد منطق العمل والكيان المستهدف MovieEntity:

lib/features/layout/demain/use_case/get_all_movies.dart 
class GetAllMovies {
  final MovieRepo movieRepo;
  GetAllMovies(this.movieRepo);

  FutureResult<List<MovieEntity>> call() async {
    return await movieRepo.getAllMovie();
  }
}
4 طبقة البيانات: الاتصال الفعلي بالإنترنت (Data Layer & Dio)

يقوم الـ MovieRemoteDataSourceImpl بإرسال طلب HTTP GET للرابط الخارجي عبر مكتبة Dio:

lib/features/layout/data/data_source/movie_remote_data_source.dart 
final response = await DioSevice.dio.get(
  'https://movies-api.accel.li/api/v2/list_movies.json',
);

if (response.statusCode == 200) {
  final Map<String, dynamic> data = response.data is String
      ? jsonDecode(response.data as String)
      : response.data;
  final movieModel = MovieModel.fromJson(data);
  return movieModel.data?.movies ?? [];
}
5 تحويل البيانات من Model إلى Entity (Data Mapping)

لكي تحافظ الشاشات على استقلاليتها، نقوم بتحويل كائنات الـ Model (القادمة من الـ JSON) إلى كائنات نظيفة MovieEntity:

lib/features/layout/data/models/movie_model.dart 
extension MoviesExtension on Movies {
  MovieEntity toEntity() {
    return MovieEntity(
      id: id ?? 0,
      title: title ?? '',
      image: mediumCoverImage ?? largeCoverImage ?? '',
      rating: rating ?? 0.0,
      year: year ?? 0,
      runtime: runtime ?? 0,
      summary: summary ?? descriptionFull ?? '',
      genres: genres ?? const [],
      backgroundImage: backgroundImageOriginal ?? backgroundImage ?? '',
    );
  }
}

ثم يقوم MovieRepoImp بلف القائمة في Right(moviesEntities) وإعادتها للـ Cubit.

⚠️ تحليل الخطأ السابق وكيف تم حله: (Exception: Unexpected Error)
السبب الجذري للمشكلة:
في ملف movie_model.dart، كان حقل التقييم rating = json['rating']; معرّفاً كـ double?.
عندما أعاد السيرفر في أحد الأفلام "rating": 0 (وهو رقم صحيح int في لغة Dart)، أطلقت بيئة تشغيل دارت الاستثناء التالي:
type 'int' is not a subtype of type 'double?' in type cast.
الحل الجذري المطبق:
تم استخدام كائن num? العام للتحويل بأمان سواء جاء الرقم 0 أو 7.8:
rating = (json['rating'] as num?)?.toDouble();
وكذلك تأمين بقية الحقول مثل genres والمصفوفات ضد قيم الـ null.
الحقل في الـ JSON طريقة القراءة القديمة (المسببة للخطأ) طريقة القراءة الجديدة الآمنة ✅
"rating": 0 json['rating'] (TypeError) (json['rating'] as num?)?.toDouble()
"year": 2026 json['year'] (json['year'] as num?)?.toInt()
"genres": null json['genres'].cast<String>() (json['genres'] as List?)?.map(...).toList()
